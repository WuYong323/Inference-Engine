## 0. 今天的问题与全景图

### 0.1 一个问题的两种问法

- **不存 S/P，反向怎么知道梯度？** 前向把 S 算完就扔了（Day 2 的承诺），但反向的 dS 需要 P 的每个元素——答案：**第二遍重算**（recompute）。前向只存 O(T) 的三个小数组（O、每块的行 max m、每块的行和 l），反向重新把 S 算出来、重建 P，用完再扔。
- **D_i 修正项扣掉的到底是什么？** softmax 的每一行**和恒为 1**——"我变大，必然有人变小"。梯度必须扣掉这个耦合项，否则算出的梯度会"违反平移不变性"。今天用两元素例子亲手把 D 项抠出来。

## 1. 反向数学：先手推，再写代码（1.5h）

### 1.1 ★ 两元素 softmax 手算 D 的来历（30min，本周解锁关键）

设只有两个 logits a、b，p = softmax([a,b]) = [p₁, p₂]，p₁ + p₂ = **1**。输出 o = p₁v₁ + p₂v₂（先取 D=1 的标量情形），上游给 do。

**先算"没扣 D 的朴素梯度"**：∂o/∂a = v₁·∂p₁/∂a + v₂·∂p₂/∂a = v₁·p₁(1−p₁) + v₂·(−p₁p₂) = p₁(v₁ − (p₁v₁+p₂v₂)) = **p₁(v₁ − o)**。同理 ∂o/∂b = p₂(v₂ − o)。

**向量化并扣掉什么**：写成 dL/ds = p ⊙ (do·v − D)，其中 D = do·o = p₁(do·v₁) + p₂(do·v₂)。验证 D 的来历：`do·v` 是"每个元素对 o 的直接贡献"，而 D 是这些贡献**按 p 的加权平均**（= 行的"平均贡献"）——朴素梯度里每个元素都多算了这个平均值，因为 **softmax 行和为 1，任何元素变大都必须有别人变小**。

**D 项的几何意义（一句话背下来）**：

```
Σ_k (dL/ds_k) = Σ_k p_k·(do·v_k − D) = D − D·Σp = 0
→ 行梯度之和恒为 0 —— 所有 logits 平移一个常数，softmax 输出不变，
  所以梯度必须"零和"。D 修正项 = 平移不变性的代价。
```

### 1.2 四公式推导（在前向公式链上逐环反传）

前向链：`S → P = softmax(S) → O = P·V`。从 do 出发逐环反传：

```
① dV = Pᵀ·dO             ← O = P·V 对 V 的梯度：P 要重算（第二遍）
② dP_raw = dO·Vᵀ        ← 反传到 P 的"原始梯度"（还没扣 softmax 耦合）
③ dS = P ⊙ (dP_raw − D_i)，其中 D_i = rowsum(dO ⊙ O_i)
                          ← softmax 层的 Jacobian = P ⊙ (· − D)：§1.1 的向量化
                          ★ D_i 用 O 与 dO 算——两者在反向一开始就有，先算一次
④ dQ += dS·K_j，dK += dSᵀ·Q_i   ← S = Q·Kᵀ/√D 的反传（缩放并进 dS）
```

**两个要点**：① D_i 是**行标量**（每行一个），先于块循环算好（只需 O 和 dO）；② dQ/dK/dV 是**跨块累加**（每行会碰多个 K 块），dQ 行独立、dK/dV 按列块累加（明天 CUDA 里 dK/dV 用 atomicAdd 或分块归约）。

### 1.3 存储账：重算 vs 存储（15min，并入推导）

```
T=2048, D=64, fp32：
  标准反向（存 S 和 P 两个 T×T 矩阵）：2 × 2048² × 4B ≈ 33.5 MB（每头！）
  FA 式（存 O + 每块 m/l）：O = Tq·D·4 ≈ 512 KB；
     m/l 每行每块 = 2 × Tq × nblocks × 4 ≈ 2 × 2048 × 32 × 4 ≈ 512 KB
  → 合计 ≈ 1 MB，省 ~33 倍，且随 T 增长倍数更大（O(T) vs O(T²)）
```

**这就是"重算哲学"的全部**：存储省下的显存，代价是第二遍重算 S/P 的计算量——**attention 是 memory-bound（Day 2 的判据），用算力换显存永远是赚的**。本日 v1.1 简化（照规划）：不追求"用 l 重建 m"的进一步省内存，三个数组照搬公式。

### 1.4 第二遍怎么重建 P（重算的正确性关键）

前向存的每块行 max 是**块内局部值 m̃**，不是全局 m。重建真权重 P 需要换算：

```
P̃ = exp(S − m̃)                        ← 第二遍重算，相对块内 max
P  = P̃ · exp(m̃ − m_global) / l_global ← 换算到全局尺度（Day 1 的 rescale 引理第三次使用）
```

（m_global、l_global 可从存的 m̃/l̃ 再推导，但 v0 反向**显式存下**，先对后省。）

## 2. torch 参考实现（1.5h，配套 `bench/ref_attn_backward.py`）

### 2.1 结构：两个 pass，各干一件事

```python
def attn_bwd_fa_style_ref(q, k, v, dO, causal=True, block_n=64):
    """FA 式分块反向的 torch 母本（明天 CUDA 版的逐行翻译对象）。
    pass1：重算前向（Day1 单因子公式），收集 O、全局 m/l、每块 m̃/l̃；
    pass2：D_i = rowsum(dO⊙O) 一次算好 → 逐块重算 S、P̃，换算成真权重 P，
           按 §1.2 四公式累加 dQ/dK/dV。
    """
    B, H, Tq, D = q.shape
    Tk = k.shape[2]
    scale = 1.0 / math.sqrt(D)
    offset = Tk - Tq
    dq, dk, dv = torch.zeros_like(q), torch.zeros_like(k), torch.zeros_like(v)
    nblocks = math.ceil(Tk / block_n)

    for b in range(B):
        for h in range(H):
            # ── pass1：重算前向，收集状态（与 Day1 单因子公式逐行一致）──
            m = torch.full((Tq,), float("-inf"), device=q.device)
            l = torch.zeros(Tq, device=q.device)
            o = torch.zeros(Tq, D, device=q.device)
            m_blk = torch.full((Tq, nblocks), float("-inf"), device=q.device)
            l_blk = torch.zeros(Tq, nblocks, device=q.device)
            for jb in range(nblocks):
                kj = k[b, h, jb*block_n:(jb+1)*block_n]
                vj = v[b, h, jb*block_n:(jb+1)*block_n]
                s = (q[b, h] @ kj.T) * scale
                if causal:
                    cols = torch.arange(jb*block_n, jb*block_n + kj.shape[1], device=q.device)
                    rows = torch.arange(Tq, device=q.device) + offset
                    s = s.masked_fill(cols[None, :] > rows[:, None], float("-inf"))
                m_j = s.max(dim=-1).values
                m_new = torch.maximum(m, m_j)
                alpha = torch.exp(m - m_new)
                p = torch.exp(s - m_new[:, None])          # 单因子（Day1 坑⑤）
                l_j = p.sum(dim=-1)
                l = l * alpha + l_j
                o = o * alpha[:, None] + p @ vj
                m = m_new
                m_blk[:, jb], l_blk[:, jb] = m_j, l_j
            o = o / l[:, None]

            # ── D 修正：一次算好（§1.2 公式③）──
            D_i = (dO[b, h] * o).sum(dim=-1)               # (Tq,)

            # ── pass2：逐块重算 + 四公式累加 ──
            for jb in range(nblocks):
                kj = k[b, h, jb*block_n:(jb+1)*block_n]
                vj = v[b, h, jb*block_n:(jb+1)*block_n]
                s = (q[b, h] @ kj.T) * scale
                if causal:  # 与 pass1 完全相同的掩码
                    ...same mask...
                # 重建真权重 P（§1.4）+ 全掩块 NaN 防护（Day1 坑⑤的 backward 版）
                m_j = m_blk[:, jb]
                m_safe = torch.where(m_j == float("-inf"), torch.zeros_like(m_j), m_j)
                p_tilde = torch.exp(s - m_safe[:, None])   # 全掩行 → exp(−inf−0)=0
                p = p_tilde * (torch.exp(m_j - m) / l)[:, None]   # 全局换算（全掩行 → 0）
                dp = dO[b, h] @ vj.T                       # ② dP_raw
                ds = p * (dp - D_i[:, None])               # ③ D 修正
                dq[b, h] += ds @ kj                        # ④ 累加
                dk[b, h, jb*block_n:(jb+1)*block_n] += ds.T @ q[b, h]
                dv[b, h, jb*block_n:(jb+1)*block_n] += p.T @ dO[b, h]
    return dq, dk, dv
```

### 2.2 与 autograd 对照（今天的硬验收）

```python
# 判据：loss = (O · dO).sum()，autograd.grad 给的三路梯度必须与母本 allclose 1e-4
# 形状矩阵：prefill 对齐 / decode(Tq=1) / 非对齐尾巴 / D=64；causal 开与关
```

**为什么用 `(O·dO).sum()` 造标量 loss**：反向公式以 dO 为输入——把"上游梯度"变成"标量损失的梯度"，autograd 就能自动给出 dQ/dK/dV 与我们手推公式对拍。**这是"手推公式 → 自动求导互证"的标准手法**（工业上实现任何新算子的 backward 都先过这一关）。

### 2.3 两个反向专属的坑（写进速查表）

① **全掩块的 NaN**（Day 1 坑⑤的 backward 版）：块对某些行全掩 → m̃=−inf → `exp(S−(−inf))` = NaN。防护：`m_safe`（把 −inf 换成 0 再减）+ 外层换算因子 `exp(−inf−m)/l = 0` 自然置零；
② **pass2 的掩码必须与 pass1 逐位相同**——mask 差一位，P 就错一行，dK/dV 静默错（测试矩阵里的非对齐用例专抓这个）。

def predict_ms_softmax(rows, H, block, variant, arch, dtype_bytes=4):

## 6. 完成标准自测（先默写再对答案）

**规划题 1**：能推 D_i 的来历。
*答案要点*：两元素例子——∂o/∂a = p₁(v₁−o)；向量化 dS = P⊙(dO·Vᵀ − D)，D = rowsum(dO⊙O) = 按 P 加权的"平均贡献"。来源：softmax 行和为 1，元素间耦合（我变大必有人变小）；性质：ΣdS = 0（平移不变性——所有 logits 平移常数不改变输出，梯度必须零和）。D 用 O 与 dO 在 pass2 之前一次算好。

**规划题 2**：说清"重算 vs 存储"的字节账（T=2048 时省多少）。
*答案要点*：标准反向存 S、P 两个 T×T：2×2048²×4 ≈ 33.5 MB/头；FA 式存 O（512KB）+ 每块 m/l（~512KB）≈ 1 MB → **省 ~33 倍**，且 O(T) vs O(T²) 随 T 放大。代价 = 第二遍重算 S/P 的算力——attention 是 memory-bound，算力换显存永远赚。

**附加题**：第二遍为什么不能直接用存的 m̃ 当全局 max？（m̃ 是块内局部值，真权重 P = P̃·exp(m̃−m_global)/l_global——Day 1 rescale 引理的第三次使用。）
